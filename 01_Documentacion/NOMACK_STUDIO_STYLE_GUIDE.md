## 1. Filosofía de Diseño: Cadena Documental de Alta Autoridad
Hereda el rigor, la precisión protocolaria y la disciplina de los dictámenes desarrollados en Génesis Legal con Daniel Moncada:
- **Semántica sobre estética:** Cada color tiene significado operativo o de riesgo; no hay elementos decorativos aleatorios.
- **Rigor de cuadrícula:** Jerarquía numérica y tabular estricta. Las cifras clave dominan el peso visual.
- **Micro-respiros deliberados:** Fondos claros y silencios visuales entre secciones para garantizar legibilidad ejecutiva sin fatiga.

## 3. Estructura Tipográfica y Markdown
1. **Títulos Principales:**
   - H1: `#2d124d` con separador inferior sólido.
   - H2: Con identificador numérico o semántico (`1.0`, `2.0`), acentuado en `#ffd231` o `#2d124d`.
2. **Cajas de Alerta Protocolaria (GitHub Alerts):**
   - `> [!NOTE]` para contexto técnico o antecedentes.
   - `> [!IMPORTANT]` para directrices clave o montos acordados.
   - `> [!WARNING]` para advertencias de cartera o DNS.
   - `> [!CAUTION]` para riesgos legales, expiración o pérdida de activos.
3. **Tablas Contables y Forenses:**
   - Encabezados con fondo `#2d124d`, texto blanco y líneas de acento `#ffd231`.
   - Alineación numérica a la derecha para valores monetarios.
   - Filas alternas con sombreado `#f5f7fa`.
   - Pie de tabla con totales consolidados y alertas de descalce.
